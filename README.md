# MNIST Adversarial Robustness with Knowledge Distillation and Diffusion Augmentation

This repository contains an MNIST adversarial robustness experiment. The project compares standard supervised learning, knowledge distillation, adversarial training, adversarial knowledge distillation, and diffusion-based data augmentation under clean, FGSM, and PGD evaluation.

The main goal is to study whether teacher soft-label supervision, adversarial training, and diffusion-generated synthetic data can improve robustness against adversarial perturbations.

## Project Overview

This project evaluates MNIST classifiers using both standard accuracy and adversarial robustness. Each model is tested on the original MNIST test set and on adversarial examples generated by FGSM and PGD.

The project includes the following model settings:

| Model                  | Description                                                              |
| ---------------------- | ------------------------------------------------------------------------ |
| `baseline`             | Standard CNN trained on original MNIST using hard labels only            |
| `standard_kd`          | Student CNN trained with hard labels and teacher soft labels             |
| `adv_training`         | CNN trained on both clean and FGSM adversarial images                    |
| `adv_kd`               | Student CNN trained with adversarial examples and teacher guidance       |
| `baseline_diffaug`     | CNN trained on diffusion-augmented MNIST without adversarial supervision |
| `adv_training_diffaug` | Adversarial training on diffusion-augmented MNIST                        |
| `adv_kd_diffaug`       | Adversarial knowledge distillation on diffusion-augmented MNIST          |

The diffusion-augmented models are trained only when `--enable-diffusion-aug` is used.

## Methods

### 1. Standard CNN Baseline

The baseline is a compact convolutional neural network trained on the original MNIST training set using cross-entropy loss. It does not use knowledge distillation, adversarial training, or synthetic data. This model provides the reference point for measuring adversarial vulnerability.

### 2. Knowledge Distillation

The teacher model is first trained with high-temperature cross-entropy:

```text
CE(logits / T, y)
```

After training, the teacher produces soft labels:

```text
softmax(teacher_logits / T)
```

The student is trained with both hard labels and teacher soft labels:

```text
loss = alpha * CE(student_logits, hard_labels)
     + (1 - alpha) * KL(student_logits / T, teacher_soft_labels)
```

In this script, `--kd-alpha` controls the weight of the hard-label loss.

### 3. Adversarial Training

Adversarial training uses both clean images and FGSM-generated adversarial images during training. The loss combines clean and adversarial classification losses:

```text
loss = (1 - adv_weight) * clean_loss + adv_weight * adversarial_loss
```

This directly exposes the classifier to adversarial perturbations during training.

### 4. Adversarial Knowledge Distillation

Adversarial knowledge distillation combines adversarial training with teacher guidance. The student model receives hard-label supervision and teacher soft-label supervision on both clean and adversarial examples.

This setting tests whether knowledge distillation can provide additional robustness when the student is already trained with adversarial examples.

### 5. Diffusion-Based Data Augmentation

When diffusion augmentation is enabled, the script trains a class-conditional DDPM on MNIST. The diffusion model generates synthetic images for each digit class. These generated images are then combined with the original MNIST training set.

The diffusion-augmented dataset is used to train:

```text
baseline_diffaug
adv_training_diffaug
adv_kd_diffaug
```

This setting tests whether adding synthetic class-conditional samples improves clean accuracy or adversarial robustness.

## Evaluation

The models are evaluated using:

* Clean accuracy on the original MNIST test set
* FGSM adversarial accuracy
* PGD adversarial accuracy

The default perturbation strengths are:

```text
[0.0, 0.01, 0.02, 0.05, 0.1, 0.2, 0.6]
```

The script supports repeated experiments with multiple random seeds. It saves both raw per-run results and summary results with mean accuracy and standard deviation.

## How to Run

### Run without diffusion augmentation

```bash
python adversarial_kd_mnist_multi_seed_diffaug.py \
  --epochs 5 \
  --batch-size 128 \
  --temperature 20 \
  --kd-alpha 0.5 \
  --num-runs 3 \
  --output-dir outputs \
  --run-name basic_run
```

This trains and evaluates:

```text
baseline
standard_kd
adv_training
adv_kd
```

### Run with diffusion augmentation

```bash
python adversarial_kd_mnist_multi_seed_diffaug.py \
  --epochs 5 \
  --batch-size 128 \
  --temperature 20 \
  --kd-alpha 0.5 \
  --num-runs 3 \
  --enable-diffusion-aug \
  --diffusion-epochs 5 \
  --synthetic-per-class 500 \
  --output-dir outputs \
  --run-name diffaug_run
```

This trains the original models and the diffusion-augmented models.

### Faster run using cached synthetic data

Training a diffusion model for every seed can be slow. After one diffusion run, the script saves generated samples as:

```text
synthetic_mnist.pt
```

You can reuse this file with:

```bash
python adversarial_kd_mnist_multi_seed_diffaug.py \
  --epochs 5 \
  --batch-size 128 \
  --temperature 20 \
  --kd-alpha 0.5 \
  --num-runs 3 \
  --enable-diffusion-aug \
  --synthetic-cache-path outputs/diffaug_run/seed_42/synthetic_mnist.pt \
  --output-dir outputs \
  --run-name cached_diffaug_run
```

When `--synthetic-cache-path` is provided, diffusion training and synthetic image generation are skipped.

These files contain per-seed results for each model.

### Summary results

```text

```

These files contain mean accuracy, standard deviation, number of runs, and individual run accuracies.

### Main figures

```text
fgsm_mean_accuracy_vs_epsilon.png
pgd_mean_accuracy_vs_epsilon.png
clean_mean_accuracy.png
```

These are the main plots for reporting final results. They show mean accuracy across repeated runs.

### Per-seed result folders

Each `seed_xx/` folder stores the models, CSV files, and plots from one individual run. These plots are useful for debugging, but the final report should mainly use the mean plots and summary CSV files.

## Important Arguments

| Argument                 | Description                                            |
| ------------------------ | ------------------------------------------------------ |
| `--epochs`               | Number of training epochs for each classifier          |
| `--batch-size`           | Batch size for training and evaluation                 |
| `--lr`                   | Learning rate                                          |
| `--temperature`          | Temperature used in knowledge distillation             |
| `--kd-alpha`             | Weight of hard-label loss in the KD objective          |
| `--adv-weight`           | Weight of adversarial loss during adversarial training |
| `--pgd-steps`            | Number of PGD attack steps                             |
| `--pgd-step-size`        | PGD step size                                          |
| `--adv-train-epsilon`    | FGSM epsilon used during adversarial training          |
| `--num-runs`             | Number of repeated runs with different seeds           |
| `--seeds`                | Manually specified seed list, such as `42,43,44`       |
| `--quick-test`           | Uses a smaller subset for faster debugging             |
| `--enable-diffusion-aug` | Enables diffusion-based data augmentation              |
| `--diffusion-epochs`     | Number of epochs for training the diffusion model      |
| `--synthetic-per-class`  | Number of generated synthetic images per class         |
| `--synthetic-cache-path` | Path to cached synthetic MNIST images                  |

## Result Interpretation

The clean accuracy results measure standard classification performance on MNIST. The FGSM and PGD results measure how accuracy changes as the perturbation strength increases.

The comparison separates the effect of different robustness strategies:

* `baseline` shows ordinary supervised learning performance.
* `standard_kd` tests whether teacher soft-label supervision improves robustness.
* `adv_training` tests whether direct exposure to adversarial examples improves robustness.
* `adv_kd` tests whether teacher guidance adds benefit under adversarial training.
* `baseline_diffaug` tests whether generated data alone improves robustness.
* `adv_training_diffaug` and `adv_kd_diffaug` test whether diffusion augmentation helps when combined with adversarial supervision.

For final reporting, use the summary CSV files and the mean accuracy plots rather than only using the individual seed plots.

---

## Notes

* MNIST is downloaded automatically by the script.
* Diffusion augmentation is slower than the non-diffusion methods.
* If `--enable-diffusion-aug` is used without `--synthetic-cache-path`, a diffusion model is trained and synthetic data is generated for each seed.
* The original MNIST test set is kept unchanged, even when diffusion augmentation is used.
